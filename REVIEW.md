# Calendar 6: review log

A running list of code and security findings for the whole project, and their history.

- **IDs** are numbered once per category and never reused, even if an item is withdrawn:
  **C** critical, **H** high, **M** medium, **L** low, **DOC** documentation, **T** testing,
  **E** enhancement.
- The tables below list the **open** items. Fixed items move to "Fixed items" at the end, with
  the commit that fixed them; withdrawn items are listed there too, with the reason (an item
  whose severity changes is withdrawn and gets a new ID in its new category).
- **Found** is the review that found the item (see "Reviews" at the end). Locations are
  `file:line` at the commit that review read; later commits may move them.

## Suggested order

No critical or high item is open.

1. **M-17** (with **L-26**): names made of digits; one bad file name takes the course down.
2. **M-19**: a missing `default.ini` must fail closed.
3. **M-18**: a real per-username rate (a "next allowed attempt" time) and IPv6 /64 counting.
4. **L-27, L-28, L-30**: server-side code and raw page source must not leak by other routes.
5. **L-31, L-32, L-33**: virtual files and assets.
6. **L-29, L-34**: harden the tag scanner and the Markdown converter.
7. **DOC-14, DOC-15**.
8. **E** items; E-1 (the front end) is the next big piece of work.

| M-17 | 6 | `lib/Course/Course.php:246-251` (`boxesOf`), `:120` | **A name made only of digits takes the whole course down:** PHP turns array keys like `"1"` or `"2024"` into integers, and with `strict_types` `strlen()` / `Place::__construct` throw, so every endpoint answers 500. | M-18 | 6 | `lib/Endpoint/AuthEndpoint.php` (per-username slow-down), `lib/Endpoint/HtmlEndpoint.php` (lock limiter) | **The per-username slow-down does not limit the guessing rate** (L-23's fix): each request sleeps 1 s on its own, so parallel requests guess as fast as the PHP-FPM pool allows (about 3 guesses/s with 5 workers, more with more), while tying up every worker. Confirmed on Apache + FPM by the reviewer. | Keep a "next allowed attempt" time per username (one guess per second, others 429 with `Retry-After`), but let a correct password through; count IPv6 addresses per /64. |
| M-19 | 6 | `lib/Course/Course.php:58-60` | **A missing `config/default.ini` publishes everything:** only an unreadable file fails closed; a deleted or misnamed file (`defaults.ini`) means "no rules", so every solution is visible, and no problem is listed.
